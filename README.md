# COCA 5000 Vocabulary Trainer

一个纯静态网页小工具，用于按频率顺序测试 COCA 5000 高频词，并把“不熟 / 不认识”的词自动加入遗忘曲线复习。

## 功能

### 1. 测试新词

- 每组 50 / 100 / 150 / 200 个词，可切换。
- 三档判断：
  - 能应用：直接标记为已掌握，不进入背词池。
  - 认识但不熟：进入背词池，安排复习。
  - 不认识：进入背词池，作为重点词安排复习。
- 支持浏览器英文朗读。
- 快捷键：`1` 能应用，`2` 认识但不熟，`3` 不认识，`S` 朗读，左右方向键切换。

### 2. 今日复习

- 自动显示今天到期的词。
- 默认复习间隔：`1, 3, 7, 15, 30, 60` 天。
- 复习时三档判断：
  - 认识并会用：进入下一轮复习间隔。
  - 认识但不熟：明天再复习，阶段轻微回退。
  - 忘了 / 不认识：明天再复习，阶段回到 0。
- 完成所有复习阶段后，词会自动标记为已掌握。

### 3. 背词池与统计

- 查看待背全部、今日到期、不太熟、不认识、已掌握、未测试。
- 支持搜索单词、词性和 rank。
- 支持导出待背词 TSV。
- 支持导出 / 导入全部学习进度 JSON。
- 进度自动保存在当前浏览器的 `localStorage`。

## 本地预览

因为浏览器直接双击 `index.html` 时可能不允许读取 `coca5000.json`，建议在项目目录运行一个本地服务器：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `coca5000-vocab-tester`。
2. 把本文件夹里的所有文件上传到仓库根目录。
3. 打开仓库 `Settings` → `Pages`。
4. `Build and deployment` 选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. 保存后等待 GitHub Pages 生成网址。

## 注意

学习进度保存在浏览器本地，不会自动跨设备同步。换设备时，请先在旧设备点击“导出进度”，再在新设备点击“导入进度”。
